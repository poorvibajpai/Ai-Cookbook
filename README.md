## 📖 What is this?

This is my personal AI Cookbook — a collection of notebooks, mini-projects, and experiments as I go deeper into AI/ML. Each "recipe" is a self-contained, runnable notebook with explanations written for humans, not just machines.

Think of it as my **learning journal + project portfolio**, built in the open.
